# Source Map Template

This file is intentionally machine-neutral. Each user should point the skill at their own local copy of the study materials.

## Recommended source priority

1. Primary Tian Ji books or lecture transcripts.
2. Detailed study notes that identify the lecture, chapter, or page.
3. Tables, spreadsheets, diagrams, and local indexes.
4. Secondary books or community notes, clearly labeled as secondary.

## Useful source categories

- Tian Ji: 天机道、地脉道、人间道
- 四柱: 八字基础、四柱命卦、干支取数、大运规则
- 紫微: 安命宫、安身宫、十四主星、四化、大限、流年
- 易经: 先天卦、后天卦、值年卦、六十四卦批语
- Supporting material: 64 卦表格、卦象图、学习笔记、课程字幕

## Search routing

Use filename search first when the user mentions a specific book, note, or table. Use text search for terms such as:

- `紫微`, `命宫`, `身宫`, `四化`, `大限`
- `四柱`, `命卦`, `先天卦`, `后天卦`, `流年卦`
- `八字`, `大运`, `财星`, `官星`, `夫妻`
- `乾为天`, `山天大畜`, or another named hexagram

If extraction is unavailable for a legacy document or scanned PDF, report the limitation and use an accessible adjacent source rather than silently guessing.
